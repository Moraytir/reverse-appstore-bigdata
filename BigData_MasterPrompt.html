Data Engineering Prompts
DE-01 — PySpark Setup Data Engineering
[วาง Master Prompt ก่อน] ช่วยเขียน PySpark script สำหรับ: 1. โหลดไฟล์ CSV ขนาด 1.5GB เข้า Spark DataFrame 2. แสดง schema และ column types ทั้งหมด 3. นับจำนวน null ในทุก column 4. นับจำนวน duplicate rows ให้ code พร้อม comment ภาษาไทยอธิบายทุกขั้นตอน และบอกว่าต้อง install อะไรบ้างก่อนรัน
DE-02 — Data Cleaning Data Engineering
[วาง Master Prompt ก่อน] ช่วยเขียน PySpark script สำหรับ Data Cleaning โดย: 1. Drop rows ที่ Average_User_Rating หรือ Reviews เป็น null 2. แปลง Released และ Updated เป็น DateType 3. แปลง Size_Bytes เป็น MB 4. ทำ boolean column จาก Developer_Website (มี/ไม่มี) 5. Filter เฉพาะแอปที่มี Reviews > 0 บอกด้วยว่าทำไมแต่ละขั้นตอนถึงจำเป็น และ trade-off ของการ drop vs impute null คืออะไร

กลุ่มที่ 2
Feature Engineering Prompts
FE-01 — Derived Features Feature Engineering
[วาง Master Prompt ก่อน] ช่วยเขียน PySpark code สร้าง derived features ต่อไปนี้: 1. Rating_Velocity = Current_Version_Score - Average_User_Rating (บวก = แอปกำลังดีขึ้น, ลบ = กำลังแย่ลง) 2. App_Age_Days = วันนี้ - Released (เป็นจำนวนวัน) 3. Days_Since_Update = วันนี้ - Updated 4. Has_Website = 1 ถ้า Developer_Website ไม่เป็น null, 0 ถ้าเป็น null 5. Developer_App_Count = จำนวนแอปทั้งหมดของแต่ละ Developer อธิบายด้วยว่า feature แต่ละตัวสะท้อนอะไรเกี่ยวกับ Apple algorithm
FE-02 — Feature Validation Feature Engineering
[วาง Master Prompt ก่อน] หลังสร้าง features แล้ว ช่วยเขียน code สำหรับ: 1. แสดง distribution ของ Rating_Velocity ด้วย histogram 2. หา outlier ใน Rating_Velocity (IQR method) 3. ตรวจว่า Developer_App_Count สมเหตุสมผลไหม (มี developer ที่มีแอปมากผิดปกติไหม?) 4. สรุป summary statistics ของทุก feature ที่สร้างใหม่ ถ้าพบ outlier ให้แนะนำว่าควร handle ยังไง

Statistical Analysis Prompts
AN-01 — Correlation Analysis Analysis
[วาง Master Prompt ก่อน] ช่วยเขียน code วิเคราะห์ว่าปัจจัยไหนมีความสัมพันธ์กับ Average_User_Rating มากที่สุด โดย: 1. Correlation Matrix ระหว่าง features ทั้งหมดกับ Rating 2. สร้าง heatmap แสดงผล 3. ระบุ top 5 factors ที่ correlate กับ Rating สูงสุด 4. อธิบายว่า correlation สูง ≠ causation หมายความว่าอะไร ในบริบทของโปรเจคนี้ และช่วยตีความผลว่ามัน support หรือ reject hypothesis ที่ว่า Apple bias toward แอปที่ update บ่อยไหม
AN-02 — Anomaly Detection Analysis
[วาง Master Prompt ก่อน] ช่วยเขียน code หาแอปที่ Rating พุ่งผิดปกติ (สัญญาณว่าอาจเพิ่ง featured โดย Apple) โดย: 1. ใช้ Isolation Forest หาแอปที่ Rating_Velocity ผิดปกติ 2. Filter แอปที่ Current_Version_Reviews สูงมาก แต่ App_Age_Days น้อย (แอปใหม่แต่ดังเร็วผิดปกติ) 3. แสดง top 20 anomaly apps พร้อม Primary_Genre อธิบายด้วยว่า pattern ที่พบบอกอะไรเกี่ยวกับ Apple algorithm
AN-03 — Hypothesis Testing Analysis
[วาง Master Prompt ก่อน] ช่วยทดสอบ hypothesis 3 ข้อต่อไปนี้: H1: Big developer (Developer_App_Count > 10) ได้ Rating สูงกว่า Indie developer (Developer_App_Count = 1) อย่างมีนัยสำคัญ H2: Free apps ได้ Reviews มากกว่า Paid apps อย่างมีนัยสำคัญ H3: แอปที่มี Developer_Website ได้ Rating สูงกว่าแอปที่ไม่มี ใช้ Mann-Whitney U Test (เพราะข้อมูลไม่ได้ normal distribution) และรายงาน p-value พร้อมตีความว่า reject H0 ได้ไหม (α = 0.05)

Dashboard & Visualization Prompts
DB-01 — Streamlit Structure Dashboard
[วาง Master Prompt ก่อน] ช่วยออกแบบโครงสร้าง Streamlit Dashboard สำหรับโปรเจคนี้ โดยต้องมี: 1. หน้า Overview — สรุปข้อมูล 1.2M แอป แบบ high-level 2. หน้า Factor Analysis — แสดง top factors ที่ correlate กับ Rating 3. หน้า Anomaly Explorer — แสดงแอปที่ Rating พุ่งผิดปกติ 4. หน้า "Will Apple Feature My App?" — Demo หลัก ให้ user กรอก: Genre, Free/Paid, มี Website ไหม, Update frequency แล้ว output โอกาสที่แอปจะถูก feature (เป็น % หรือ score) เขียน Streamlit code structure พร้อม navigation และบอกว่าแต่ละหน้าควรใช้ chart แบบไหน
DB-02 — Key Visualizations Dashboard
[วาง Master Prompt ก่อน] ช่วยเขียน code สร้าง visualization สำคัญ 4 อัน: 1. Bubble Chart — x=Reviews, y=Rating, size=App_Age_Days color=Primary_Genre (แสดง market landscape) 2. Bar Chart — Average Rating เปรียบเทียบระหว่าง Big Developer vs Indie Developer 3. Scatter Plot — x=Days_Since_Update, y=Rating_Velocity (หา pattern ว่า update บ่อยแค่ไหนดีที่สุด) 4. Heatmap — Correlation matrix ของทุก feature ใช้ Plotly เพื่อให้ interactive ได้ใน Streamlit
